# Mana Sahayam — All-India Welfare & Scholarship Navigator

A bilingual (English & Telugu) civic-tech web application helping citizens discover eligible Central and State government welfare schemes, scholarships, and subsidies filtered by **State → District → Mandal → Rural/Urban** area.

## Key Features
- **3-Step Guided Wizard:** Citizen & Household Intake → Matched Opportunities → Interactive Scheme Guide
- **Voice & Bilingual Support:** Telugu/English Speech-to-Write and Audio Read-Aloud
- **Anti-Fraud & Privacy:** Scam Link Shield (.gov.in / .nic.in verifier) and zero Aadhaar/ID collection
- **Accessibility:** Global A+ Large Text scaling and High-Contrast mode
