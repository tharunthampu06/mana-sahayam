# Mana Sahayam — All-India Welfare & Scholarship Navigator

A trilingual (**English, Telugu & Hindi**) civic-tech web application helping citizens discover eligible Central and State government welfare schemes, scholarships, and subsidies filtered by **State → District → Mandal → Rural/Urban** area.

## Key Features
- **3-Step Guided Wizard:** Citizen & Household Intake → Matched Opportunities → Interactive Scheme Guide
- **Trilingual Voice & Audio Support:** English, Telugu (తెలుగు), and Hindi (हिन्दी) Speech-to-Write and Audio Read-Aloud
- **Anti-Fraud & Privacy:** Scam Link Shield (.gov.in / .nic.in verifier) and zero Aadhaar/ID collection
- **Accessibility:** Global A+ Large Text scaling and High-Contrast mode
- **Citizen Action Tools:** Household Benefit Bundler, Document Readiness Progress Bar, .ics Calendar Deadline Alerts, and WhatsApp/Print Action Slips
